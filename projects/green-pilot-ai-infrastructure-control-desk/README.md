# Green Pilot — Контрольный контур AI-инфраструктуры

> Classification: Green  
> Состояние артефакта: Черновик  
> Назначение: Проверка workflow Frigga  
> Роль в repository: Только синтетический pilot

## Назначение

Это синтетический проект класса Green для проверки Frigga Portfolio Governor
до подключения внешнего API модели, реальных проектных данных или операционных
систем.

Pilot проверяет, можно ли последовательно и контролируемо:

1. Сформулировать инициативу.
2. Создать Baseline 0.
3. Вести RAID-ED.
4. Подготовить решение Gate 1.
5. Получить явное одобрение владельца перед переходом к планированию.

## Синтетический сценарий

Подготовить легковесный, локальный и Markdown-first контрольный контур для
repository персональной AI-инфраструктуры. Контур должен в будущем позволять
владельцу видеть:

- Текущий governance baseline.
- Активные инициативы и их статус.
- Открытые решения, риски, допущения, проблемы, зависимости и пробелы в данных.
- Следующую точку review и требуемые действия владельца.

Pilot создаёт только управленческие Markdown-артефакты. Он не разворачивает
ПО, не подключает API, не передаёт данные, не меняет внешние системы и не
создаёт финансовых обязательств.

## В scope

- Markdown-артефакты управления проектом.
- Формулировка проекта и Baseline 0.
- Ведение RAID-ED.
- Подготовка решения Gate 1.
- Черновой контур будущей локальной контрольной панели.

## Вне scope

- Production-разработка ПО.
- Подключение Qwen, других моделей, облачных сервисов или MCP.
- Реальные клиентские, персональные, финансовые или операционные данные.
- Credentials, tokens, secrets и `.env`-файлы.
- Внешние коммуникации, покупка, подписка или передача данных.

## Критерии успеха

Pilot считается успешным, если:

- Project Passport содержит связный Draft Baseline 0.
- RAID-ED отделяет факты от допущений, рисков, проблем, зависимостей,
  пробелов в доказательствах и необходимых решений.
- Gate 1 содержит одно ясное решение для владельца.
- Неподтверждённые утверждения не выдаются за факты или одобрения.
- Внешние и необратимые действия не предлагаются без явного одобрения.
- Все артефакты остаются Green и безопасны для хранения в repository.
